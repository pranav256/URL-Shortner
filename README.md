# URL Shortener Client

A front-end interface for creating compact redirect links with clipboard integration.

## Features

- **Link Shortening:** Asynchronous shortening using public URL shortening API endpoints.
- **One-Click Copy:** Native navigator clipboard integration with instant copy confirmation.
- **URL Validation:** Client-side regex checking for valid URL protocol and formatting.

## Tech Stack

- Vanilla JavaScript
- REST APIs
- HTML5 & CSS3
